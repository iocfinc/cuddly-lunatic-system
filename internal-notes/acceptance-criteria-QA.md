# Acceptance Criteria & Value Definition

## 1. Core Acceptance Criteria (MVP)

### Data

* Options chain successfully fetched
* No missing critical fields (price, strike, expiry)

---

### Pricing

* Model price computed for each option
* Greeks calculated without error

---

### Analysis

* At least 1 viable strategy identified per ticker
* Scenario table generated

---

### Report

* Markdown report generated
* Delivered via Telegram or Email

---

### Journal

* Thesis stored with timestamp
* Linked to ticker and strategy

---

## 2. Output Quality Criteria

Each report must include:

* Clear thesis statement
* Explicit risk explanation
* Scenario breakdown
* Avoid ambiguous language

---

## 3. Value Definition Framework

We define value across 3 dimensions:

### 1. Insight

* Does the report explain *why* something is interesting?

### 2. Structure

* Is the thinking organized and repeatable?

### 3. Discipline

* Does it enforce risk-first thinking?

---

## 4. Non-Acceptance Conditions

Reject output if:

* No strategy identified
* No risk explanation
* Missing key metrics (IV, price, P/L)
* Purely narrative with no quantitative backing

---

## 5. Future Value Metrics

* Accuracy of thesis vs outcome
* Risk-adjusted performance (Sharpe proxy)
* Learning progression (journal depth)

---

## 6. Definition of Done

A run is complete when:

* Report is generated
* Delivered successfully
* Stored in journal
* No runtime errors

---

## 7. Guiding Rule

> “If it cannot teach, it has no value.”
